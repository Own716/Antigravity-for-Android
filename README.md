请优先通过 **[GitHub Releases 官方发布页](https://github.com/Own716/Antigravity-for-Android/releases)** 下载。发布页会列出当前版本说明、安装包和校验文件。

1. 打开 [Releases 最新发布页](https://github.com/Own716/Antigravity-for-Android/releases/latest)。

3. 按 Android 系统提示完成安装；如系统要求，允许当前安装来源安装应用。

## 构建（开发者）

本地构建需要 JDK 17 与 Android build-tools 在 PATH 中：

```bash
bash build.sh                  # 标准版 → dist/antigravity.apk
bash build.sh --region-bypass  # 绕区版 → dist/antigravity-region-bypass.apk
```

也可以用 GitHub Actions 自动打包（`.github/workflows/build.yml`）：在 Actions 页手动运行，或推送 `v*` 标签，成品会签名后发布到 Releases。发布签名钥匙存放在仓库的 Secrets 中（`KEYSTORE_BASE64`、`KEYSTORE_PASSWORD`、`KEY_ALIAS`、`KEY_PASSWORD`），不进入代码仓库。

版本号位于 `config/app.env`（`APP_VERSION_NAME` / `APP_VERSION_CODE`），发版时递增。
